Information Architecture

How NestDay flows.

NestDay opens on Today — the one screen a parent needs every morning. The bottom tab bar reaches the four everyday destinations in one tap, and the quieter record-keeping screens live one level deeper, where they are easy to find but never in the way.

Navigation rules behind the map

Today is home

There is no separate dashboard. The app opens where the day is, and the tab bar’s first item always returns there.

Four tabs, no more

Today, Weekly, Subjects, and More. Attendance, Portfolio, Trips, and Settings are weekly-or-less tasks, so they live under More instead of competing for thumb space.

Adding is always the + button

A single gold action button adds a lesson, a sample, or a trip — the same gesture, in the same place, on every list screen.
