# NestDay — Mobile App UI Concept

**Live demo:** https://brittanynation.github.io/mobile-app-ui-concept/

NestDay is a fictional homeschool planner app, designed as an original mobile UI concept. It is built for a parent teaching at home: today's lessons, the week ahead, subject progress, attendance, work samples, and field trips — all in a soft sage palette that feels calm rather than clinical.

## Roles this project supports

- **Junior UI/UX Designer**
- **UI Designer**
- **Web Designer**
- **Front-End Designer**

## What it demonstrates

- **Mobile UI systems** — seven app screens built from one shared component kit: cards, chips, progress bars, list rows, toggles, a phone frame, and a consistent bottom tab bar.
- **Screen flows** — a CSS-only flow map (`flow.html`) showing how the screens connect, with Today as home and record-keeping one level deeper under More.
- **Consistent components** — the same patterns repeat unchanged across screens, so the system is the design point, not just individual pages.
- **Accessible basics** — semantic landmarks, aria labels on navigation, descriptive labels on the phone mockups, and dark ink text on light sage surfaces for safe contrast.
- **Responsive presentation** — the gallery and flow pages are mobile-first and responsive; the app screens are presented centered in a CSS phone frame.

## How it was made

Brittany's design workflow runs in **Sketch and Webflow**. This demo is hand-built in plain HTML and CSS (one shared `styles.css`, no frameworks, no external images — visuals are CSS and simple glyphs only) so the concept can be explored live in a browser via GitHub Pages.
